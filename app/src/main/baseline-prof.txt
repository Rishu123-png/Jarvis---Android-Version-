# J.A.R.V.I.S. — a startup profile, by hand.
#
# Profile-guided dex layout is worth 15–30% off cold start, and almost all of that is the AOT
# compiling the code the first screen actually touches. This is a *starting* profile: the classes
# below are the path from the launcher to the first frame — the activity, Compose's runtime, the
# theme, and the state holders the HUD needs on the way up.
#
# It is deliberately short, and deliberately class-level: a hand-written method signature is a guess
# about a generated name, and a wrong guess is a warning that teaches everyone to ignore warnings. The
# honest way to finish it is `./gradlew :app:generateReleaseBaselineProfile` on a device, which
# replaces this file with a measured one.
#
# Installed at first run by androidx.profileinstaller, which is why that dependency exists.
